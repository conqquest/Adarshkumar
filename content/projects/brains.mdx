**Brains** is a production-grade, highly available web application architecture designed and deployed on AWS as a case study in cloud engineering and automated infrastructure.

## Architectural Highlights

- **High Availability & Fault Tolerance** — Deployed across 2 Availability Zones (us-east-1a, us-east-1b) behind an AWS Application Load Balancer (ALB) with health checks (`/api/health`) and dynamic target groups.
- **Auto-Scaling Group (ASG)** — Dynamic capacity scaling between 2 and 4 EC2 instances based on target CPU utilization tracking (50% target threshold).
- **Infrastructure as Code (IaC)** — Fully automated Terraform module provisioning 20+ AWS resources including VPC, public/private subnets, Internet Gateway, NAT Gateway, Security Groups, ALB, ASG, and IAM roles.
- **Containerized Microservices** — Docker multi-stage builds separating React/Vite frontend static delivery via Nginx and Node.js/TypeScript Express API server connected to MongoDB.
- **CI/CD Pipeline** — GitHub Actions workflow executing automated linting, unit testing, Docker image building/tagging, EC2 image deployment, and zero-downtime rolling updates.
- **Experimental Verification** — Validated under load tests, simulated single-instance failure (automatic ALB drain and ASG replacement), and automated deployment rollbacks.
