The **Full-Stack Enterprise ERP System** is a robust, production-ready web application designed to digitize and automate core business and manufacturing operations. 

## Key Highlights

- **Business Process Automation** — Digitizes and automates manufacturing lifecycles, completely replacing manual ledgers and papers.
- **Inventory Scaling** — Capable of processing and tracking over 1,000 inventory items concurrently with secure state checks.
- **Cloud Infrastructure** — Implemented automated continuous deployment (CI/CD) pipelines, hosting the React frontend on Cloudflare Pages and the RESTful APIs on Render to achieve a 99.9% uptime.
